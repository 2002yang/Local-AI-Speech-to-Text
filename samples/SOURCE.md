# 测试音频来源

- `chinese.wav`：在项目电脑上使用 Windows 11 内置 Microsoft Huihui Desktop 中文语音生成，约 12.54 秒。
- `english.wav`：在项目电脑上使用 Windows 11 内置 Microsoft Zira Desktop 英文语音生成，约 10.48 秒。
- 人工参考文本保留在 `reference.txt`。这两段是合成语音，不是真人麦克风录音，不包含真人声纹。
- `tests/fixtures/browser-recorded.webm` 来自英文样本经 Chromium MediaRecorder 重新编码。

项目所有者已明确同意将这些项目测试样本随公开 GitHub 仓库发布。此同意不等于第三方语音许可已完成法律核实；Windows 内置语音输出的再分发条款尚未独立核实，本项目不为第三方权利授予额外许可。若需要明确的再分发授权证明，应替换为自行录制或具明确许可的音频。

用户用于问题排查的私人 `.weba` 录音不在仓库中。
