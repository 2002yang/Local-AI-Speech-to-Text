# 需求理解与边界

原题：[面试考核题-v1](https://docs.qq.com/markdown/DRlJ2aGlKaWxJVnB4?)。目标是 **B/S、本地 CPU 中英文语音转文字**，而非云端 API、语音翻译或多用户生产系统。

| 编号 | 必须实现的行为 | 对应验证 |
| --- | --- | --- |
| F1 | 浏览器授权、开始/停止、状态/计时、60 秒自动停、完成后可再次录音 | 浏览器中文英文实录，权限拒绝测试 |
| F2 | 上传 WAV 与浏览器实际录音格式；共用后端识别 | 两种来源调同一接口，真实音频测试 |
| F3 | 本地模型识别中文普通话与英文，选择语言确实作用于推理，不翻译 | 真实模型两语测试，语言传递测试 |
| F4 | 显示选定语言、状态、文本、音频实际时长、处理耗时及复制 | 浏览器 UI 测试 |
| F5 | 权限/设备错误、空/损坏/非法/超限文件、模型或推理失败、无语音 | API + 浏览器异常测试 |
| F6（可选） | 讲话时分片发送、本地推理、持续更新文字，停止后返回最终文本；允许短分片近实时 | WebSocket 自动化、真实中英文模型、浏览器音频链路及真人验收 |
| API | GET `/health`、POST `/api/transcribe`、GET `/`；规定字段与状态码 | pytest |
| 测试/交付 | pytest、真实模型、中英样本及参考文本、手动验收、README 与四份文档、OpenCode 证据 | 测试报告和最终检查 |

## 经用户确认的项目边界

- 浏览器录音最长 60 秒自动停止；服务端对上传/录音音频以实际解码时长设置 **65 秒**上限，保留编码缓冲。原题并未限制上传为 65 秒，这是本项目约定。
- 上传文件最大 10 MiB（题目建议 10 MB，统一在代码和页面使用 MiB）。
- 项目内所有文件位于当前根目录下：`app/`、`static/`、`tests/`、`samples/`、`models/`、`docs/`。
- 一个用户本机使用，文件不长期存储。不实现数据库、登录、历史、TTS 或云端调用。
- 实时识别属于可选加分项；用户在确认普通录音可用后授权实施，目前已实现，真人实时验收待完成。必做项和交付材料仍按原题单独核对。

## 必须特别注意

- 默认 pytest 不下载模型、不需物理麦克风；真实模型测试单独开启并实际记录。
- 模型权重可以首次下载，但准备后运行及识别不访问外网。
- 样本必须有合法分发权限并附人工参考文本；需要实际真人麦克风和断网验证，不以合成语音或 Mock 冒充。
- 规定启动与测试命令保持不变，Python 版本固定为 3.12；模型缺失给用户明确提示，不产生伪造结果。
